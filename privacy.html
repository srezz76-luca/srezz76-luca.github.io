Informativa sulla privacy di SkyNet

SkyNet è un'applicazione ad uso personale, utilizzata unicamente dal suo proprietario.

Dati Google utilizzati

L'applicazione accede in sola lettura (permesso calendar.readonly) agli eventi di un calendario Google del proprietario: titolo, data, orario, luogo e note degli eventi.

Come vengono usati

I dati servono esclusivamente a generare riepiloghi e risposte che vengono inviati al proprietario stesso tramite Telegram. Non vengono venduti, ceduti o condivisi con terzi, né usati per pubblicità.

Conservazione

I dati del calendario non vengono archiviati in modo permanente: vengono letti al momento della richiesta. Sul computer del proprietario è conservato soltanto il file di autorizzazione all'accesso, che può essere revocato in qualsiasi momento da https://myaccount.google.com/permissions

L'uso dei dati ricevuti dalle API di Google rispetta le Google API Services User Data Policy, inclusi i requisiti di Uso Limitato.
